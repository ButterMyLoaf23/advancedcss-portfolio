Unit 5: Typography System

Fluid type and semantic tokens

A type system that scales with the page

This page shows the modular scale, role tokens, and custom heading font I added to the shared CSS architecture.

The numeric layer

Major-third modular scale

Each step grows by about 1.25 times the step below it. The larger steps use clamp() so they grow smoothly instead of jumping at a breakpoint.

XS Supporting text

SM Small labels

MD Body text

LG Small headings

XL Section titles

2XL Large headings

3XL Display text

The semantic layer

Roles keep components readable

Components use names such as body, caption, heading, and display instead of choosing a numeric scale step directly.

This paragraph uses the shared body size and line height so longer text stays comfortable to read.

The hierarchy stays flexible

The body size remains steady while the larger headings scale between their minimum and maximum values. This keeps the hierarchy readable on a phone and still gives the desktop version enough emphasis.
