What I changed

My typography system

I used this page to test the new font sizes, line heights, and heading font for Unit 5.

Part one

The size scale

I chose a major-third scale. Each step is about 1.25 times the step before it, and the larger sizes use clamp().

XS Supporting text

SM Small labels

MD Body text

LG Small headings

XL Section titles

2XL Large headings

3XL Display text

Part two

The names I use in CSS

Instead of choosing a number every time, my components use names like body, caption, heading, and display.

Body role

This uses the shared body size and line height for normal paragraphs.

--font-size-body

Heading role

This heading uses the custom font

--font-size-heading-sm

Caption role

This is for small supporting information.

--font-size-caption

One last test

Resizing the page

The body text stays about the same size, but the bigger headings grow and shrink between their minimum and maximum values. I used this section to check the page at different widths.
