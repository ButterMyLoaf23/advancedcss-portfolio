The CSS properties

Use the normal property when one exists

Weight: I use font-weight for the wght axis.

Slant: I use font-style for the slnt axis.

Optical size: I leave font-optical-sizing: auto on so the browser can adjust the design for the rendered size.

Custom axes: I use font-variation-settings for CASL and MONO because they do not have their own CSS properties.
