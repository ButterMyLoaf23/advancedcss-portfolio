Writing modes and text flow

Designing for every direction

Logical properties describe space relative to the direction text flows, so the same layout can support left-to-right and right-to-left languages.

One component, two directions

The property map

Spacing

margin-inline and padding-block describe the text-flow axes instead of fixed screen sides.

Sizing

inline-size and block-size replace width and height when the writing mode can change.

Alignment

text-align: start keeps content aligned with the beginning of the current inline direction.
