CSS Attribute Selectors

A hands-on demonstration of presence, exact-match, substring, data-attribute, case-insensitive, and specificity selectors.

1. Presence Selector: [attribute]

A presence selector checks whether an element has an attribute, regardless of its value.

[disabled] { opacity: 0.5; cursor: not-allowed; }
What to notice: The disabled button automatically becomes faded because CSS detected the disabled attribute.

2. Exact Match: [attribute="value"]

We can select an element when an attribute has an exact value.

input[type="email"] { border: 2px solid blue; }
What to notice: Only the email input gets the blue border because its type attribute exactly equals email.

3. Substring Matchers

There are three especially useful substring matchers:

  • ^= — starts with
  • $= — ends with
  • *= — contains
[href^="https"] /* starts with */ [href$=".pdf"] /* ends with */ [class*="grid"] /* contains */
Starts with: https://example.com
Ends with: report.pdf
Contains: my-grid-layout
Memory trick: The arrow-like ^ points toward the beginning, while $ represents the end. The * is broad and means the text can appear anywhere.

4. Practical Demo: Styling Links by Destination

Attribute selectors are especially useful for links because the href already tells us what type of link it is.

a[href^="https"] { color: green; } a[href^="mailto:"] { color: purple; } a[href$=".pdf"] { color: red; } a[href$=".png"], a[href$=".jpg"], a[href$=".webp"] { color: orange; }

What to notice: No extra classes were added to these links. CSS reads the href and automatically determines the styling.

5. Data Attributes: data-*

Custom data attributes can store information about an element. CSS can then use those values to change the appearance of the element.

<div class="card" data-status="active"> Active Card </div> .card[data-status="active"] { border-color: green; }

6. Case-Insensitive Matching: i

The i flag tells CSS to ignore capitalization when matching an attribute value.

[data-code="abc" i] { border: 3px solid blue; }
data-code="abc"
data-code="ABC"
data-code="AbC"
What to notice: All three boxes match because the selector uses the i case-insensitive flag.

7. Specificity

Attribute selectors have the same specificity weight as class selectors:

Class selector: .example Specificity: 0, 1, 0 Attribute selector: [data-color="blue"] Specificity: 0, 1, 0

Key idea: Attribute selectors can be combined with element selectors, classes, and other attribute selectors. Combining selectors increases specificity.

Key Takeaways

  • [attr] checks whether an attribute exists.
  • [attr="value"] checks for an exact value.
  • ^= means starts with.
  • $= means ends with.
  • *= means contains.
  • Attribute selectors are great for styling links based on their destinations.
  • data-* attributes can describe component state or variants.
  • attr() can read an attribute value for generated content.
  • The i flag makes attribute matching case-insensitive.
  • Attribute selectors have the same basic specificity weight as classes: 0, 1, 0.
